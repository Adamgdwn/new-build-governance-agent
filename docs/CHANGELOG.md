## Unreleased

- 2026-11-08: Secret env files are now restricted to the current user on Windows too (Chunk Forty-Seven). On Windows, `os.chmod(0o600)` changes only the read-only flag, so `.env.master` and project env files kept their folder's access. `env_file.write_private_text` now restricts every secret file before writing to it: mode 0600 on POSIX, and on Windows `icacls` removes all inherited access and grants the current user full control. On Windows, explicit entries are kept. In Python's own temp folders those are SYSTEM, Administrators, and Owner Rights. If the restriction fails, nothing is written and the command stops with a fix hint. The new order also closes a short window on POSIX where a new file held secrets at the default mode before `chmod` ran. `env_sync.py`, `master_env.py`, and `stripe_provision.py` all write through the new helper.
